# Colosseum Resources Skill

AI agent skill for Colosseum hackathon builders across the ecosystems in the published resource index. The advisor selects the builder's ecosystem first, then recommends project-specific tools, SDKs, infrastructure, sponsor resources, and build paths from that track's live data.

Recommendations stay within the selected ecosystem. Missing sponsor, RPC, or resource coverage is reported honestly instead of being filled with entries from another track.

## Install

```bash
npx skills add ColosseumOrg/colosseum-resources
```
